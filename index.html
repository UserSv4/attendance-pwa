РАБОТАЕТ БЕЗ ИНТЕРНЕТА

Установите «Отметку»

Сначала установите приложение, а уже внутри добавляйте список — тогда данные не потеряются при переходе из Safari.

  1. 1

    Нажмите «Поделиться» в Safari.

  2. 2

    Выберите «На экран “Домой”», затем «Добавить».

  3. 3

    Откройте «Отметку» с экрана «Домой» один раз с интернетом.

  4. 4

    Дождитесь надписи «Готово офлайн». Дальше интернет не нужен.

iPhone не разрешает сайту нажать «Установить» за вас. Весь список хранится только на вашем устройстве.
